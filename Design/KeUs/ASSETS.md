# 素材来源

本包仅带网页使用的素材，没有用户聊天截图、真实药单、财务资料或私密人格文件。

| 素材 | 来源与用途 |
| --- | --- |
| `assets/koi.png` | 内置图像生成的透明粉白锦鲤；一张素材绘制两条鱼。生成记录 `exec-09c6c689-9c38-4f96-8279-d828a5f103b9.png`。 |
| `assets/petal-water-v2.png` | 内置图像生成的宽薄粉白山茶花瓣，透明背景；记录 `exec-b6ffbd1f-e820-4080-bf1f-36cb3837b3ec.png`。 |
| `assets/water-background.png` | 内置图像生成的水面底图，保留基础样式引用；记录 `exec-5503ee50-5c0d-4520-b475-25bd766be53a.png`。 |
| `assets/water-calm-v2.png` | 水面底图的生成编辑版，移除固定圆形波纹；活动涟漪由网页绘制。记录 `exec-f6b18bdb-1ac5-4911-877e-7f193646e2b2.png`。 |
| `assets/moon.png` | 复用既有 App 的 `WatercolorMoon.imageset/watercolor-moon.png` 概念素材。 |
| `assets/PinyonScript-Regular.ttf` | 复用既有 App 字体资源；随附 `PinyonScript-Regular-OFL.txt` 许可。用户已确认所有英文装饰花体使用它。 |

既有 Allura 和 Snell 字体名仍可能出现在底层回退样式中；最终生效的花体由 `palettes.css` 的 `PondPinyon` 和 `notebooks.css` 指定，不另打包 Allura。原生接入遵守交接中的 Pinyon 约定。

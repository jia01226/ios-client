# 柯 · 月隐与长窗（单文件交互原型）

当前入口是 `index.html`。CSS、JavaScript、思源宋体 250 字重子集、Pinyon Script 和月隐 PNG 素材均已内联，独立文件约 2.7 MB。下载这一份 HTML 即可；不需要旁边的 assets、spec 或后端。字体授权及素材来源附在 HTML 末尾。

默认象牙纸色。全部数据为示例；修改、语录和旧窗快照只保存在页面内存，刷新重置。模型、电话、清理与换窗都不调用真实服务。普通本地 HTML 的复制权限由浏览器决定；直接复制不可用时显示可全选的文字框。

## 查看

直接用支持本地 HTML 的浏览器打开，或在本目录运行：

```sh
python3 -m http.server 8774 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8774/`。此地址只属于运行服务的电脑，不是手机公网链接。将 HTML 文件转存手机，或放到你选择的静态托管地址后，可用手机浏览器查看。本次未发布网站。

## 状态入口

顶部横向滚动的演示目录包括：聊天页、打开抽屉、话笺、来信、素笺、换窗、挑选带走、长按菜单、已钉住的消息、小心思、电话、语录、旧窗回看、洗澡完成、换窗确认、换窗完成。右上开关统一隐藏演示说明。

- 聊天默认渲染最近 5 轮，共 10 条；可以展开完整 34 轮示例历史。
- 每轮绑定我的一句和柯紧接着的回复；初始钉住 8 轮，约 6k，最近 5 轮内有 2 轮带标记。
- 挑选默认最近 20 轮与全部钉住轮取并集，初始 24 轮、约 14k、5 段。勾选、分段和用量会重新计算。
- 明确标注的历史省略段是示例间隔，不包含可选择的隐藏消息；计算相邻段时不会跨过这一间隔合并。
- 长按 520ms、鼠标右键、普通点击或键盘激活气泡都能打开菜单。钉住标记可点击查看整轮说明。
- 横划超过 65px 且横向意图明显才开关抽屉；时间、滑杆等控件不触发横划。抽屉宽度为手机框的 75%。
- “洗澡”把示例容量降低 20%，每窗演示一次，原话不改。演示目录的“洗澡完成”会重设示例容量以便重复查看。
- 换窗前保存完整旧窗快照，所选原话 ID 作为带走列表保存；聊天仍保留历史可回看。点击演示目录的“换窗完成”会创建一次示例快照。

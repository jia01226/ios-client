# 月隐 · 设置抽屉设计记录

本记录根据 `7602c46` 的网页源码与 spec 提取，仅适用于 `Design/KeSettings/`。当前状态为视觉提案，等待用户继续确认；不代表原生 App 已实现或通过真机验收。仓库根目录的设计记录属于其他界面，不作为本预览的颜色或花体依据。

## 设计意图

把零散设置收进右侧的浅纸抽屉。目录用藤蔓、山茶、月亮珠链和静止蝴蝶形成留白，入口分布在两侧；进入二级页后移除装饰，以清楚的设置行呈现内容。左侧始终露出原页面，保留当前位置的连续感。

| 内容 | 真源 | 实际使用 |

## 颜色和字体

四纸色固定为浅雾蓝 `#F3F8FC`、冷白 `#FAFCFD`、暖白 `#FCFAF5`、浅米色 `#F4EFE5`。只提供白天样式。正文 `textPrimary`、说明 `textSecondary`、分隔线 `line`、强调 `accent`、按钮文字 `onAccent` 和焦点 `focus` 均引用 tokens 的 day 角色。

中文为 Songti SC / STSong / SimSun / serif。英文装饰字使用本地 Pinyon Script（CSS 别名 PondPinyon），授权为随包 OFL；不可换成根目录设计中的其他花体。版本与示例天数用 Baskerville，时间输入使用系统字体。

目录标题 32px，窄屏 30px；目录雅称 24px，窄屏 22px；副标签 12px。二级页标题 28px / 40px，花体 27px / 1.5，组标题 17px / 26px，设置行 16px / 1.6，说明 12px / 1.8。具体选择器以 CSS 为准，不能将共享字阶全部机械套用。

## 空间和素材

抽屉占手机容器宽度 75%，顶部工具条 48px；目录最小高度 720px，矮屏纵向滚动。二级页左右留白 20px，设置行最小高度 58px，主要按钮最小高度 44px。右边缘拖动带宽 20px，另有 44px 月牙入口；桌面外侧演示按钮在窄屏为 36px，不能当作 App 控件规范。

目录坐标从可滚动目录内容的左上角计，不包含顶部工具条。PNG 使用完整透明画布、object-fit: contain；不要裁剪透明边再照抄位置。各层的位置、大小和透明度见 layout.art；普通装饰饱和度 .55，蝴蝶 .35。蝴蝶三层共用 46 × 46px 画布并旋转 -16deg。底纸由颜色绘制。

layout 中的 anchor 目前是交接描述，网页没有将它转换成 transform-origin；目录标题定位、工具条和二级页留白等仍由 CSS 固定。原生接入时以浏览器实际排版核对，不要把 JSON 中所有字段都假设成已被读取。

## 动效与可访问性

月牙或右边缘向左拖打开；遮罩、关闭按钮或向右拖关闭。弹簧参数为 stiffness 350、damping 38、mass 1。超过 8px 且横向位移至少为纵向的 1.2 倍后接管；纵向滚动及输入控件不被拖动抢走。释放采用 0.18 秒速度投影和 0.5 阈值。原页面保持挂载，覆盖层透明，仅抽屉纸面绘底色；向右弹簧完成后直接隐藏，避免再叠第二次退出动画。

二级进入位移 10px / 180ms。装饰静止；减少动态效果时取消空间动画。打开时底页 inert，Tab 在抽屉内循环；Escape 先回目录，再关闭。返回目录恢复滚动位置与入口焦点；关闭后恢复打开前焦点。控件使用强调色轮廓与 2px 焦点框。

## 已确定的设计

- 冷白底色、灰粉水彩、雾蓝细节；保持简洁留白。
- 页首使用「团子小鱼与无叶山茶花」透明 PNG。
- 数字使用 **Didot（纤细款）**，文字保留宋体类衬线风格。
- 周历的班次直接放在对应数字下方；不再使用独立班次卡片。
- 月历在首页原地展开、收起和切换月份；不通过跳转新页面展开。
- 荷包、食单、药盒、纸条采用两列纯文字、细分隔线和轻箭头，不加入口图标。

## 范围

核心审核对象是「我们」首页及内嵌月历。四个功能子页、设置及排班编辑页是已有原型的辅助流程，供点击验证，不代表子页视觉已全部最终确认。侧栏的「排班编辑 · 辅助页」与首页内嵌月历是不同用途。

「柯」和「柯的」底栏入口在本包中禁用；本轮正在尝试的「柯的」新 UI 未收录。`app.js` 保留了原型公共运行时中的部分未使用函数；路由已限制在本包范围，审核不要将未暴露函数视为已确认设计。

## 文件

- `index.html`：源文件入口。
- `style.css` / `app.js`：原型公共样式与运行时。
- `cool.css` / `cool.js`：本次确认的视觉与「我们」页覆盖逻辑。
- `assets/`：实际使用的图片、Lucide 本地脚本及许可证。
- `preview-standalone.html`：可离线打开的单文件预览，与源文件对应。
- `screenshots/`：从本包运行结果截取的审核图片。
- `asset-provenance.json`：小鱼山茶素材的生成方式与提示词。
- `manifest.sha256`：文件校验值，不包含压缩包本身。

源文件可在本目录运行 `python3 -m http.server 8768 --bind 127.0.0.1`，访问 `http://127.0.0.1:8768/`。

## 数据、字体与限制

- 天数 128、日期 2026-10-29、金额等均是示例；刷新后重置。不发送请求到真实服务。
- 周历固定演示 10 月 26 日至 11 月 1 日。正式落地必须换成实际日期、真实班次和用户数据。
- 整月日历使用真实年月天数计算，但选择其他月份后收起仍回到固定示例周；这是原型限制。
- Didot 为当前 Mac 已安装的系统字体，未复制或分发字体文件；其他系统会回退。iOS 落地需确认字体可用性与动态字号。
- 需重点审核淡色文本的对比度、触控区域、窄屏布局和大字号可用性。

## 落地要点

1. 原生旋转图使用正方形母版，`rotationEffect` 的 anchor 为 `.center`；不要按图片非透明外框重新裁切。几何中心也是拖动计算中心。
2. 旋转中心放在右侧容器边缘，图只露约半朵。网页设计宽度最多 390 CSS px；大花框 520 px，小于等于 350 px 时用 420 px。SwiftUI 需按实际可用空间和安全区调整，不能全屏拉伸图片。
3. 入口 ID 绑定实际路由，不把数组下标用作业务标识。六档间隔 `360 / 6 = 60°`；选中项、下方文字与进入目标读取同一对象。
4. 拖动角度用 `atan2`，跨 ±180° 修正差值；松手取最近档位。拖动结束应吞掉同次点击，防止多跳一档；取消手势后正常恢复。
5. 点击入口只选择，点击下方动作再进入；返回不丢失选择。切换入口不能伪造真实内容、未读或消息状态。
6. 左侧文字和花朵触控区不得相互抢触摸；保留至少 44 pt 可点区域。减弱动态时取消旋转过渡，文字选择照常可用。VoiceOver 可直接选择六个入口，无需完成旋转手势。
7. 默认奶白背景，淡粉作为预览候选。本轮不要求全 App 统一换皮；动态字号、深浅模式和其他已存在设置要在原生实现中核对。

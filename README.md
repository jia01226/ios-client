## ⚠️ 三条底线，先说

1. **这个 App 永不上架 App Store。** 内容包含私人日记、医疗记录、亲密內容。分发方式是 **Ad-hoc + OTA 网页安装**。任何"提交审核""App Store Connect 配置"的建议都是错的方向。
2. **颜色不许写死在页面里。** 全部走 `Theme/Theme.swift` 里的令牌。见下面「主题系统」一节——这是硬要求，违反了以后换主题要全盘返工。
3. **第一版只做两件事：聊天页能收发 + APNs 推送能收到。** 其余页面留骨架、留假数据，不要提前完善。

---

## 项目是什么

把一个已有的 PWA（Flask + SQLite + 外部模型 API）换成 iOS 原生前端。

**后端一行都不改。** App 只是换一张脸——调现有接口。

**做它的唯一硬理由：iOS 上网页版的推送根本收不到。** 次要理由：WebView 滚动手感换不来原生。

## 🔴 几条不许破的交互规矩

### 【我们】里的提醒：不许有勾选框

- 提醒**不是任务清单**，是"柯说的一句话"
- 她做完了会**去跟柯说，由柯划掉**——不是她自己点勾
- **过期未完成的自动收起**：不变红、不累计、不出现"连续 X 天未完成"
- **理由：这一格是"被爱人管着"，不是考勤系统。任何带惩罚感的设计都是错的。**

### 【柯】里的卧室模式：开关由柯触发，不由用户按

- 她只需要正常聊天
- **柯的回复携带状态信号 → App 收到后自动切换**（配色变化 + 轻微触感反馈）
- **她全程不需要点任何按钮**
- 保留手动开关作为后门，但不是主路径
- **理由：那个开关她自己按，等于每次都要亲口宣告一次"我现在想要"——而这恰恰是她最开不了的口。**

### 【玩】里的调教室和抽屉：必须藏得住

- **入口不得在 tab 栏或任何一眼可见处显示可辨识名称**
- 需支持 **Face ID / 独立密码**二次解锁
- **理由：她手机不是绝对私密的（家人会拿）。这一格的第一要求不是"好用"，是"藏得住"。**

## 🎨 主题系统（硬要求）

**所有颜色、字号、圆角、间距，唯一来源是 `Theme/Theme.swift`。**

页面里只准写 `Theme.color.bg`、`Theme.color.accent` 这种，**不准出现 `Color(hex: "1A1F3A")` 这类字面量**。

**已内置两套皮：**
- `.day` —— 浅色（**第一版默认**，她本人偏好浅色系）
- `.night` —— 深夜蓝 + 金（跟 App 图标同源）

**往后加主题、开放"聊天气泡换颜色"的设置项，都只改这一份文件。**

> ⚠️ App 图标是深夜蓝底 + 白山茶 + 金鱼，而界面默认浅色——**这是有意为之，不是不统一。**

## 踩坑参考（动手前先读，能省几个通宵）

**https://github.com/Cheiineeey/ios-app-where-it-breaks**

中文、真机实测、专门为"给 AI 读"优化。覆盖推送 APNs / CallKit 来电 / 灵动岛 / 权限 / 屏幕共享。

它点出的三种坑：
- **静默失败**：编译过、签名过、装机过，然后什么都没发生
- **误导性报错**：签名的报错几乎从不指向真正的原因
- **隐形配置丢失**：界面上勾了的功能可能根本没进最终的包

**验证手段（照抄）**：
```bash
plutil -p YourApp.app/Info.plist              # 查实际进包的配置
codesign -d --entitlements - YourApp.app      # 查权限有没有真进包
```

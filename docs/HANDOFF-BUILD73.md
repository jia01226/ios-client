## 本轮前端

- 班次模板可新建、自己命名、改名、改一段或两段时间、删除。删除只移出可选列表，日期上的既有名字和时间快照保留。更改模板只更新今天和未来的同类班次，某天单独调整的时间保留。
- 排班仍用 `fetchShifts / setShift / deleteShift`，没有增加服务器字段。班名写 `shift`，具体时段与用户备注写 `note`。模板库存在本机；每个已排日期照旧同步，柯能读取。周、月表点击已排日期直接取消。
- 「玩」空出的中间位置加山屋，八个物件全部可打开。原创 SwiftUI 线条绘图，使用现有主题；没有复制参考仓库的图片或字体。山屋固定走 test1 的 Cookie 会话，只读记忆，唯一写入是用户点提交的小锁信。提交失败留草稿，提交成功后刷新失败也不误报为发送失败。
- 浅色「我们」将纪念日、周班表、月历收在一个「日历」区域，通过日子／周班表／月历切换；纪念日编辑可直接进入。经期的「来了」「走了」放在第一屏，记录与删除可从「经期」打开。深夜保留原布局和色板，补同样的经期入口。

## 经期接口已接通

本轮用户明确授权直接收尾并更新网页安装。VPS 实际 test1 经期表已有 `end_date` 列，但开始路由与存储函数参数不一致，查询未返回结束字段，且没有单独结束路由。已按实际运行文件制作窄补丁并部署：

```http
POST /ke-test1/api/periods/end
Content-Type: application/json

{"id": 现有记录ID, "end_date": "YYYY-MM-DD"}
```

成功返回 `{"ok":true}`；查询在原记录返回结束日期。重复同日操作幂等、非法日期和缺失记录报错。柯的上下文读取实际结束状态。网络失败仍保留本机待同步结束日期，查询确认以前不假报成功。

山屋真实 GET 返回已经用本次 Swift 解码器核对通过。没有向真实账号发送测试小锁信。部署范围、测试与回滚位置见 `deployment/README.md`。

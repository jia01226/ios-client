## 便利贴：服务器待 Claude 接，不可宣称已联通

现有 goodlove 没有独立便利贴接口。不能复用 `/api/moments`：它会生成朋友圈语境和自动回复。客户端已做单独接口、离线草稿保护和明显的未同步提示；没有改服务器，也没有发送真实测试记录。

请 Claude 在实际安装前接以下契约：

- `GET /api/sticky-notes` 返回数组：`[{"id":"UUID/string","author":"user 或 ai","content":"正文","created_at":"ISO8601 UTC"}]`。
- `POST /api/sticky-notes` 请求 `{ "id": "客户端稳定 UUID", "content": "正文" }`，返回完整同一条对象。author 必须由服务器固定 user；客户端不能写成柯。相同 id 重试必须幂等；已有 ai id 不允许覆盖。
- `POST /api/sticky-notes/delete` 请求 `{ "id": "..." }`，只能删除 user 的便签；缺失 id 幂等成功，不可删除柯的记录。
- 柯写入/读取便利贴的工具和上下文接入由 Claude 完成；同一权限范围内双方可读，不引入动态、点赞、评论或自动朋友圈回复。
- 日期统一返回 ISO8601 UTC，按当前聊天服务的认证和数据隔离处理。客户端按 ChatLine scope 保存未确认草稿。

只在服务器返回相同 id、正文和 user 作者后标记同步成功；失败或超时保留原稿和 id，重试不会新建重复便签。

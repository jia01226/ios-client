## 先看预览

进入 `Design/KeSettings/`，运行：

```sh
python3 -m http.server 8774 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8774/`。默认展开设置；`?open=0` 从底页开始。不能直接用 file:// 读取示例 JSON。所有素材和字体均在本地，不依赖外部 CDN。

`index.html` 是结构，`style.css` 是排版样式，`app.js` 是示例交互，`motion.js` 是抽屉弹簧与释放判定。
示例“柯、我们、柯的”三个底页只用于演示所有页面都可打开同一个抽屉，不是现有 App 页面的替换设计。

## 两层结构

目录名“月隐”，短诗“一枝收月色”。抽屉从右边进入，占手机内容宽度 75%；左侧 25% 保留原页面，可点击关闭。上方月牙按钮和右边缘向左划都能打开。目录及二级页均支持向右划关闭。

| 路由 / data-id | 雅称 · 功能 | 第二层 |
| --- | --- | --- |
| settings-chat | 话笺 · 聊天 | 气泡、壁纸、模型选项 |
| settings-visits | 来信 · 柯来找你 | 是否主动联系、多少、跨午夜安静时段 |
| settings-reminders | 晚声 · 提醒 | 吃药、到家、睡前开关及时间 |
| settings-palette | 素笺 · 底色 | 浅雾蓝、冷白、暖白、浅米色 |
| settings-notifications | 铃语 · 通知 | 新消息、日记朋友圈、日常提醒、新版本 |
| settings-privacy | 藏心 · 私密 | 面容解锁、私密空间 |
| settings-updates | 新枝 · 更新 | 示例版本、打开更新页占位动作 |
| settings-about | 小序 · 关于 | 示例版本、给 Claude 留话 |

二级列表不带装饰花枝，以清楚易改为主。设置修改只保留当前页面内存，刷新重置；留言也不会真实发送。没有权限申请、真实解锁、通知或更新下载。

## 颜色、字体和布局

- `spec/tokens.json` 原样沿用 `codex/us-preview` 的 KeUs 清单；本预览只读 `colors.day` 和四个 `palettes.*.dayPaper`。不开放夜间模式。
- 四纸色：浅雾蓝 `#F3F8FC`、冷白 `#FAFCFD`、暖白 `#FCFAF5`、浅米色 `#F4EFE5`。
- 中文宋体；英文花体固定 **Pinyon Script**，字体和 OFL 授权已随素材提供。不要替换成另一种连笔花体。数字用 Baskerville，系统时间控件保留系统字体。
- `spec/layout.json` 定义目录内的归一化位置；坐标原点是可滚动目录内容左上角，不包含 48px 顶部工具条。图片坐标是完整透明画布框，使用 contain，不要裁掉透明边缘后照搬坐标。
- 目录最小高度 720px。矮屏允许滚动，不把八个入口挤到一屏。常规点击范围至少 44px；右边缘手势带宽 20px，另有 44px 月牙按钮作为等价入口。
- 专属设计记录已补齐，见 `Design/KeSettings/DESIGN.md` 与 `Design/KeSettings/.impeccable/design.json`；记录按实际源码提取，视觉仍待用户继续确认。页面具体坐标以 layout 为准。细节页中文标题 28px、正文 16px、说明 12px、花体 27px；目录雅称桌面 24px/窄屏 22px。

## 拆分素材

均在 `Design/KeSettings/assets/`，PNG 自带透明 Alpha。`@3x` 的原始逻辑画布尺寸为像素尺寸除以 3；最终在页面按 layout.json 缩放，保留源文件原始分辨率，不用猜测裁切边界。

| 文件 | 像素尺寸 | 用法 |
| --- | --- | --- |
| vine@3x.png | 724 × 2172 | 独立藤蔓，不含花、蝴蝶或月亮 |
| moon-tassel@3x.png | 887 × 1774 | 月亮与珠链流苏组合，独立一层 |
| flower@3x.png | 348 × 348 | 已确认的山茶花，页面复用两次 |
| wing-left@3x.png | 192 × 192 | 蝴蝶左翅 |
| wing-right@3x.png | 192 × 192 | 蝴蝶右翅 |
| body@3x.png | 192 × 192 | 蝴蝶身体 |

蝴蝶三张画布完全同尺寸、叠在同一位置，预览整体为 46 × 46px。藤蔓、月亮是新生成素材；山茶和蝴蝶沿用 KeCamellia 已有素材。详细来源、生成描述与尺寸在 `spec/asset-provenance.json`，每张 PNG 也嵌有来源描述。花和蝴蝶不是本次重新生成的，原始生成提示不可考，已明确标注。

底纸由颜色绘制，无需整屏背景贴图。插画统一降低饱和度和透明度，取值以 layout 和 CSS 为准。

## 动效和退出约定

参数源 `spec/motion.json`：弹簧 stiffness 350、damping 38、mass 1；拖动超过 8px 且横向意图明显后才接管，纵向滚动不截走。释放按当前位置加 0.18 秒速度投影，超过 0.5 打开，否则关闭。动画可被中途拖动打断，保留速度。二级进入位移 10px / 180ms。

原页面始终保留，覆盖容器本身透明，只有 75% 抽屉纸面绘制底色。关闭只播一次向右弹簧，到终点立即隐藏覆盖层；不要再叠系统全屏关闭动画。此约定为设计示意，不表示本次验证了原生 103 的修复。

装饰默认静止，避免设置目录不断晃动。减少动态效果时直接切换；键盘焦点限制在抽屉，关闭后回到打开按钮。实际 App 需对应做好 VoiceOver、字体放大和安全区适配。

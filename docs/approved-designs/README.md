# 佳佳最后确认的设计

这些是设计图，**不是模拟器截图**。应结合源代码和真实运行结果核对，不能用图里的示例日期、班次或聊天内容冒充真实记录。

- `us-and-calendar.png`：第六版左右结构；左侧纪念日、表白日、我的生日、柯生日，右侧天数和日期；去掉 with you。双人便利贴、周班表、月历向下展开。生成图中的班次仅为排版示例，App 周/月视图共用同一真实数据。
- `chat.png`：四页共用浅粉，浅粉灰/雾粉气泡，贴底细导航。Thinking 的 Allura 字体、字号、位置、展开和动效逻辑保留；消息布局与正文排版沿用原代码。
- `play.png`：只留塔罗、双弈（五子棋）。
- `diary.png`：山茶月牙日记封面，可翻页；右侧月光日期条选择年月日。
- `drawer.png`：仅作造型/材质方向参考；当前使用 SceneKit 原生几何实现，光滑漆面，上层能拉开，下层锁住。实际视觉贴合度仍需模拟器截图检查，不能视为已还原到图中材质精度。

生产素材已位于 `KeApp/Assets.xcassets/`。设计图由内置 image_gen 生成；完整生产素材提示词见 `../moonlight-assets.md`。没有改服务器或安装页。
